# hpl_ruralMarket_prototype

Rural-market price finder for Indian agricultural commodities — commodity price
discovery, price trends, geospatial arbitrage, and net-revenue comparison across
196 markets in 9 states, with a bilingual (English/Hindi) UI.

## How to run

**Terminal 1 — backend (Express API on http://localhost:4000):**

```bash
cd backend
npm install
npm run format-csv && npm run generate   # build the dataset from Agmarknet CSV
npm run dev
```

**Terminal 2 — frontend (Vite dev server on http://localhost:3000):**

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000. The vite dev server proxies `/api` to
`http://localhost:4000` (override with `VITE_API_URL`; see `frontend/.env.example`).

## Data

Prices come from the Agmarknet marketwise report of 2026-09-06 (reported in
Rs./quintal, converted to Rs./kg throughout the app). Daily trends are synthetic
estimates anchored on real modal prices, generated by the backend.
